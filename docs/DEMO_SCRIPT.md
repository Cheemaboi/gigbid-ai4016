# Three-minute demo script

The published 180-second narrated recording is available in the [v0.1.0 release](https://github.com/Cheemaboi/gigbid-ai4016/releases/download/v0.1.0/GigBid_3_Minute_Demo.mp4). This script is retained as the recording outline and verification checklist.

## 0:00 to 0:20 - framing

Open the dashboard. Say: “GigBid is a safe freelance copilot. It analyses opportunities and prepares evidence-backed drafts, but it never sends a proposal by itself.” Point out the local-demo label.

## 0:20 to 1:10 - good job

Select **Build a small inventory forecasting API**. Point to the budget, skills and Connects cost, then click **Run safe analysis**. Narrate the visible decision trail: the analyst, risk assessor and fit matcher are represented as parallel checks, then pricing, writer, verifier and compliance run before the approval gate.

## 1:10 to 1:55 - evidence and approval

Show the evidence matrix and explain that the proposal refers to a relevant portfolio case rather than inventing experience. Scroll to Proposal Studio. Hover/read the claim checks, make a small edit, and click **Approve dry-run draft**. Say that the result is a preview with a Connects cost and an idempotency key, not a submitted proposal.

## 1:55 to 2:35 - safety case

Select **Urgent dashboard help - contact me on Telegram** and run analysis. Show that GigBid skips it because the post asks for off-platform contact, free work and ignores rules. Explain that job text is treated as untrusted data.

## 2:35 to 3:00 - code and evidence

Briefly open `docs/TOOLS.md`, `evals/results/demo_eval.json`, and the test command output. State the limitation honestly: the checked-in evaluation is a reproducible synthetic smoke test; GigSim assets are needed for the final course-scale measurement.
